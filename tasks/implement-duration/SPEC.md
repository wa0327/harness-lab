# duration 規格

## parse_duration(text) -> int

- 單位：`w`（週，604800 秒）、`d`（86400）、`h`（3600）、`m`（60）、`s`（1）。不分大小寫。
- 每個片段是「非負整數 + 單位」，例如 `1h`、`30m`，數字和單位之間不能有空白（`"1 h"` 是 `ValueError`）。也接受小數，格式必須是「整數部分 + `.` + 恰好一位小數」，例如 `1.5h` = 5400；`1.h`、`.5h`、`1.25h` 都是 `ValueError`。小數換算後必須是整數秒，否則 `ValueError`（如 `0.1s`）。
- 片段之間可以有任意空白，也可以沒有：`"1h30m"`、`"1h 30m"`、`" 2d  4h "` 都合法。
- 單位必須由大到小排列，且每個單位最多出現一次：`"30m1h"`、`"1h1h"` 都是 `ValueError`。
- 純數字（沒有單位）視為秒：`"90"` = 90。但純數字不能和其他片段混用：`"1h 30"` 是 `ValueError`。
- 開頭可以有一個負號，表示整段為負：`"-1h30m"` = -5400。負號只能出現在最前面。
- 空字串、只有空白、未知單位、缺數字（如 `"h"`）都是 `ValueError`。

## format_duration(seconds) -> str

- 用 `d`、`h`、`m`、`s` 輸出（不用 `w`），由大到小，省略為 0 的單位：3723 → `"1h2m3s"`，3600 → `"1h"`。
- 0 → `"0s"`。
- 負數加負號前綴：-90 → `"-1m30s"`。
- 非整數輸入是 `TypeError`（`bool` 也算非法）。

## 往返性質

對任何整數 `n`，`parse_duration(format_duration(n)) == n`。
